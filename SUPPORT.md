# Support

Use the right channel so questions and reports can be handled efficiently.

- **How-to or usage question:** open an issue in the relevant repository with the environment, version, expected result, and actual result.
- **Bug report:** use the bug report template and include a minimal reproduction, logs with secrets removed, and regression information when known.
- **Feature idea:** use the feature request template and describe the user problem, proposed outcome, and constraints.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities in a public issue.
- **Contribution question:** read [CONTRIBUTING.md](CONTRIBUTING.md), then open an issue if the guidance is unclear.

Please search existing issues before opening a duplicate. Avoid including credentials, access tokens, personal data, or production data in any report.
